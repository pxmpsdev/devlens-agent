# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in DevLens, please report it privately
via GitHub's security advisory system: https://github.com/devlens/devlens/security/advisories

Please do not open public issues for security vulnerabilities.

We will respond within 48 hours and work with you to verify and address the issue.

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | ✅ |
| < 0.1   | ❌ |

## Security Considerations

- DevLens analyzes source code locally and does not send any data to external servers
- No secrets or credentials are required for operation
- Git analysis only reads local repository data
- No telemetry or analytics are collected
